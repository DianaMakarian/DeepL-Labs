# deepL-labs

## Лабораторна робота №1 (`Lab1/`). 
**Тема:** Реалізація та перевірка зворотного поширення похибки

**Мета роботи:** Реалізувати зворотне поширення похибĸи (backpropagation) вручну та перевірити отримані градієнти двома способами: за допомогою PyTorch autograd і чисельного диференціювання. 

## Лабораторна робота №2 (`Lab1/`)
**Тема**: Поріг рішення під асиметричну ціну помилоĸ

**Мета роботи:** Дослідити вплив вибору порогу класифікації ($t$) на якість роботи моделі в умовах сильного дисбалансу класів та асиметричної вартості помилок ($C = 10 \cdot FN + FP$). 
Реалізувати та верифікувати алгоритм точного швидкого пошуку оптимального порогу $t^*$ через швидкий алгоритм, порівняти його з прямим перебором та оцінити результати на тестовій вибірці.
